Turn an agent error into a bug report.

Choose a Claude Code or Codex CLI session. Copy the failing call into an issue or team chat. Commands, paths and conversations stay on your machine.

Where is my session file?

Open one saved JSONL file (up to 20 MiB) from the folders below. On macOS press ⌘⇧G in the file picker to enter the path.

Claude Code  ~/.claude/projects/
Codex CLI  ~/.codex/sessions/

On Windows paste a path into File Explorer’s address bar:

%USERPROFILE%\.claude\projects
%USERPROFILE%\.codex\sessions

If you set CLAUDE_CONFIG_DIR or CODEX_HOME, start in that folder.

What stays private?
Prompts, replies, commands, raw output, paths, custom tool names, IDs and timestamps stay out of the card. A distinctive sequence may reveal your workflow. Review the preview before sharing.
