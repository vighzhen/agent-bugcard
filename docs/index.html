Report an agent failure privately.

Turn a Claude Code or Codex CLI session into a GitHub issue attachment. Share the failing tool call and keep your commands, paths, and conversation on your machine.

Find my session file

Open your user folder and choose one JSONL file from the relevant subfolder (up to 20 MiB). On macOS, press ⌘⇧G in the file picker to enter a folder path.

Claude Code  ~/.claude/projects/
Codex CLI  ~/.codex/sessions/

On Windows, use %USERPROFILE% in place of ~. A custom CLAUDE_CONFIG_DIR or CODEX_HOME changes the base folder.

What stays private?
Prompts, replies, commands, raw output, file paths, custom tool names, IDs and timestamps stay out of the receipt. A distinctive sequence of calls can still reveal a workflow. Review the Markdown before sharing.
