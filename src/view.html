Where is my JSONL file?
Claude Code usually saves sessions under ~/.claude/projects/. Codex CLI uses ~/.codex/sessions/. Look in their subfolders for the session you want. On Windows, start in your user folder. A custom CLAUDE_CONFIG_DIR or CODEX_HOME changes the base folder.
Choose one file up to 20 MiB. The browser reads the chosen file locally.


What stays private?
Prompts, replies, commands, raw output, file paths, custom tool names, IDs and timestamps stay out of the receipt. A distinctive sequence of calls can still reveal a workflow. Review the Markdown before sharing.
